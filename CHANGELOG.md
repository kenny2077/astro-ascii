# Changelog

## Unreleased

### Changed

- Replaced the solar system's synthetic terrain with credited photo-derived maps.
- Removed the solar viewer's strict-ASCII option; retained a single dot style.
- Removed the clipped RGB exposure boost, enlarged the globes, and increased dot resolution.

### Added

- Solar-system collection: Sun, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune, now with a 48-second display cycle.

- Procedural black-hole artwork and an existing animated GIF preview.
- Local-photo ASCII / pixel comparison with no bundled third-party photograph.
- Source checks, frame tests, CI, contribution guide, and attribution records.

This is the initial collection, not a stable SDK release.
